# Changelog



Versions follow semantic versioning: major for breaking changes, minor for new features, patch for fixes.



## 1.1.1 — 2026-11-13

Release notes polish

- Fixed text encoding in release notes and the version button.

## 1.1.0 — 2026-11-13



Smoother drawing and selection



- Select shapes and groups only when fully enclosed by the selection frame.

- Duplicate or paste groups as independent groups.

- Hold Ctrl and drag to move the view temporarily.

- Choose from 11 shapes in the new Add object menu.

- Select and edit objects only on the active layer.

- Start new shapes and lines with the default style.

- Open dated release notes from the version button.



## 1.0.0 — 2026-11-09



Introducing IconMaker



- Draw and edit SVG icons with layers, groups, curves and shape tools.

- Style icons, undo changes, and export SVG or PNG.

- Choose a theme and accent colour, with automatic local saving.
